# Dades del mapa

La primera versió descarrega les dades de carrers d'OpenStreetMap quan s'executa el programa. No desa automàticament una còpia local del mapa.

Si més endavant es vol afegir memòria cau o dades pròpies, aquesta carpeta és el lloc previst per a fitxers de dades. No hi posis informació personal o claus d'API.
